상위 프로젝트의 URL 정규화 테스트에는 더미 사용자명/비밀번호가 들어 있는 테스트 fixture 1개가 있습니다. 테스트 맥락과 더미 값임을 확인하고 보존했습니다. 계정 인증 데이터나 실제 연결 권한은 포함하지 않습니다.

이 기록은 공유 파일과 설치 절차의 검증입니다. 홍성용 님 PC에서의 전체 설치, 공급자 계정 권한, OAuth 로그인, 유료 API 호출, Blender·Ghidra·브라우저의 실제 실행까지 검증했다는 뜻은 아닙니다. 필요한 외부 프로그램·계정은 각 구성요소 안내에 따라 준비해야 합니다.
