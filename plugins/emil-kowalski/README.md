# Emil Kowalski Design Skills for Codex

Personal plugin containing 13 skills from Emil Kowalski's official repository.

Source: https://github.com/emilkowalski/skills
Commit: 85e8e2363b713506e1d5b6e07a0eb2da66be1bc3
License: MIT (see LICENSE).

This local plugin packaging is not an official published Codex plugin.
The upstream project provides skills, not an MCP server. No login or API key is needed.

Use the skills in your next Codex turn, for example:
- Use emil-design-eng to improve this interface.
- Use animate to build a polished transition.
- Use review-animations to review the motion in this component.

See UPSTREAM-README.md for all skills and upstream documentation.

Compatibility: three explicit-only invocation settings were translated to agents/openai.yaml. Skill instruction bodies are unchanged; see UPSTREAM.json.
