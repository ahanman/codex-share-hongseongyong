# Playwright personal Codex plugin

This portable wrapper runs the official Microsoft Playwright MCP package pinned to `@playwright/mcp@0.0.82` through `npx`. Install Node.js/npm and Google Chrome on the receiving computer; `npx` must be on PATH. The first server start may download the package.

The browser is headless and uses Playwright's own browser profile. Sign in to sites normally when required. This package contains no browser profile, cookies, access token, or account session.

Upstream: https://github.com/microsoft/playwright-mcp
