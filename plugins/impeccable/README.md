# Impeccable for Codex

Personal Codex bundle of the official Impeccable design skill and its 24 commands.

Official source: https://github.com/pbakaus/impeccable
Pinned commit: 83c2c735777c68e30ea536ab9cc97f7843456945

Includes the official Codex skill, command references, nested agent definitions, and Windows engine launcher. Automatic project hooks are not configured by this personal skills plugin.

This is personal plugin packaging, not an official published Codex plugin. The upstream provides skills, not a standalone MCP server; no MCP endpoint is configured.

Example requests:
- Use $impeccable to audit this interface.
- Use $impeccable to polish the current UI.
