# Google Flow (Browser)

Personal Codex plugin with the `google-flow-browser` skill. Uses the already-installed connected browser tools (or a separately authenticated Playwright MCP browser).

No dedicated Flow MCP server is included. A Google-published Flow MCP/API integration was not verified during setup. This plugin is not published or endorsed by Google.

Open a new Codex task to load the skill, then ask to use Google Flow. Browser access was checked on 2026-09-22 at https://flow.google.com/ without generating media or consuming credits.

Official service: https://flow.google.com/
Official help: https://support.google.com/flow/answer/16353333
