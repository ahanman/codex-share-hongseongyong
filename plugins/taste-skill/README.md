# Taste Skills for Codex

Personal Codex bundle of the 13 official Taste frontend design and image-reference skills.

Official source: https://github.com/Leonxlnx/taste-skill
Pinned commit: 5217fb45be2c0b302f29c9cd31cbd3237501c684

Contains the upstream default v2 experimental skill and the separately named v1 compatibility skill. Individual skills are selected according to the task. The optional Stitch-specific skill does not install or connect Google Stitch.

This is personal plugin packaging, not an official published Codex plugin. The upstream provides skills, not a standalone MCP server; no MCP endpoint is configured.

Example requests:
- Use $design-taste-frontend to design this page.
- Use $gpt-taste to improve this frontend.
- Use $redesign-existing-projects to review this UI.
