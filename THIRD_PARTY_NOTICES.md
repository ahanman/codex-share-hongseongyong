# 원본 구성요소 및 라이선스

이 저장소는 여러 저작자의 스킬·플러그인과 설치 안내를 묶은 환경 이전 패키지입니다. 전체를 단일 라이선스로 재허가하지 않습니다. 각 구성요소의 원래 라이선스, 저작권 표시, 사용 조건을 유지합니다.

- 사용자 스킬의 출처와 포함 범위: [docs/SKILLS.md](docs/SKILLS.md), [inventory/skills.json](inventory/skills.json), `licenses/skills/`.
- 개인 플러그인의 출처와 라이선스: [docs/PLUGINS.md](docs/PLUGINS.md) 및 `plugins/` 안의 LICENSE/NOTICE 파일.
- MCP 소프트웨어와 런타임 의존성: [docs/MCP.md](docs/MCP.md). 외부 소스는 원본 제공 경로에서 설치하며 해당 라이선스가 적용됩니다.
- OpenAI 공식/독점 또는 재배포 허가를 확인하지 못한 플러그인 payload는 복사하지 않고 목록과 재설치 경로만 제공합니다.
- 이 저장소를 위해 새로 작성한 루트 설치·검증 스크립트와 안내 문서는 MIT 라이선스로 제공합니다. 타사 파일의 권리를 변경하지 않습니다.
